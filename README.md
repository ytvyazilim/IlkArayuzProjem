# IlkArayuzProjem

C#, .NET ve Avalonia UI kullanılarak geliştirilmiş masaüstü arayüz pratik uygulaması.

## Özellikler
- Dinamik komut listeleme (`foreach` ile `ListBox` doldurma)
- Seçim olayları (`SelectionChanged`) ve `is` desen eşleştirme ile güvenli tip kontrolü
- Seçimi temizleme (`SelectedItem = null`) ve durum mesajı güncelleme
- `TextBox` ve `Button` ile listeye yeni eleman ekleme (`try / catch / finally` ve boş girdi kontrolü)

## Kullanılan Teknolojiler
- C# & .NET
- Avalonia UI (XAML & Code-Behind)
